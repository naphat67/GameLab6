# Animation assets

The contents in `bone_maps/` and `libraries/Humanoid/` come from [catprisbrey/Godot4-OpenAnimationLibraries](https://github.com/catprisbrey/Godot4-OpenAnimationLibraries), following the assignment's download list. The upstream repository describes these files as Godot 4.x animation libraries and notes that a properly mapped game-development skeleton is required. Verify upstream terms before redistributing these resources outside the project.

`characters/Astra_MK06.glb` is the rigged model used in the game. Its editable Blender source is stored in `characters/source_blender/`.
